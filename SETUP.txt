8. FIRESTORE SETUP (do this once)
================================================================
   a. console.firebase.google.com > Add project (NOT garrett-apps).
      Skip Google Analytics.
   b. Build > Firestore Database > Create database > Start in
      PRODUCTION mode > pick a region > Enable.
   c. Build > Authentication > Get started > Sign-in method >
      Anonymous > Enable. (The ops console signs in this way; the
      subject app never authenticates.)
   d. Firestore > Rules tab > paste the contents of firestore.rules
      from this repo > Publish.
   e. Project settings (gear) > scroll to "Your apps" > click the
      web icon </> > register an app > COPY the firebaseConfig object.
   f. Paste that object in TWO places, replacing "null":
        index.html   -> var FIREBASE_CONFIG = null;
        gpi.html     -> var FIREBASE_CONFIG = null;
      It should end up looking like:
        var FIREBASE_CONFIG = { apiKey:"...", authDomain:"...", ... };
   g. Re-upload both files. Bump gpi.html's version badge and the
      CACHE string in sw.js together whenever gpi.html changes.

   VERIFY: open gpi.html, log in, the mode line should read
   "MODE: LIVE — synced as <YOURNAME>." If it says AUTH FAILED, step (c)
   was missed.
